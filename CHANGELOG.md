# Changelog

Все заметные изменения Xynapse документируются в этом файле.

## 1.108.0 — 2026-09-05

Первый публично проверяемый выпуск Xynapse IDE на базе Code OSS 1.108.0.

### Добавлено

- встроенный Xynapse Assistant с режимами Chat, Plan, Agent и Full;
- Council/BVC-процесс для планирования, независимого анализа и взаимной
  критики решений;
- стартовая конфигурация десяти актуальных моделей Yandex AI Studio;
- локальные профили Xynapse и безопасное резервное копирование профиля при
  первом запуске portable-версии;
- воспроизводимая Windows x64 сборка и проверка путей перед очисткой временных
  каталогов;
- исполняемые тесты протокола расширения, режимов инструментов и шаблона
  первичной настройки.

### Исправлено

- обработка tool calls для Yandex OpenAI-compatible API и Anthropic Claude;
- маршрутизация команд между расширением и webview;
- ограничения инструментов для разных режимов работы;
- сборка GUI, расширения и зависимостей из чистого дерева исходников;
- устаревшие домены и ссылки в runtime-коде;
- экранирование аргументов для Git stash и проверка путей перед удалением
  каталогов в portable-скриптах;
- хранение только имён credential-файлов в `account.json` с автоматической
  миграцией старого формата без дублирования секретов;
- обновление Electron до исправленного patch-релиза 39.8.10 и прямых runtime-
  зависимостей Code OSS до версий без известных production-audit уязвимостей;
- отключение телеметрии по умолчанию.
- исключение несовместимого вызова Electron `setPath('appUpdate')` в режиме
  обновлений через GitHub;
- корректные сведения об издателе и исходном имени Windows EXE;
- типизация пустых списков расширений в сборочных скриптах;
- проверка релизных файлов на локальные ключи без вывода значений секретов.

### Проверка

Точные команды, результаты и ограничения выпуска приведены в
[`RELEASE-VERIFICATION.md`](RELEASE-VERIFICATION.md). Старый синтетический
перечень «1000 тестов» больше не используется как свидетельство качества.
