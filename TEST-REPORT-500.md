# Архивный отчёт тестирования

Ранее этот файл содержал искусственно разбитый перечень из 1000 пунктов. Эти
пункты не были самостоятельными исполняемыми тестами, поэтому их количество и
процент успешности нельзя использовать как доказательство качества релиза.

Для Xynapse 1.108.0 он заменён воспроизводимой проверкой:

- реальные наборы Vitest, Jest и TypeScript-проверки выполняются командами из
  [`RELEASE-VERIFICATION.md`](RELEASE-VERIFICATION.md);
- итоговые числа берутся только из вывода тестовых раннеров;
- Windows-сборка проходит отдельную проверку запуска в изолированном профиле;
- опубликованные файлы повторно скачиваются из GitHub Release и сверяются по
  SHA-256.

Название файла сохранено только для совместимости со старыми ссылками.
